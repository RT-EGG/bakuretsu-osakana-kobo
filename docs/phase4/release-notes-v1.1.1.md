# 爆裂おさかな工房 v1.1.1 リリースノート

## 概要

`v1.1.1`は、再生中の音量変更、ミュート、ミュート解除が実際の音声へ反映されるまでの遅延を
100 ms以内へ短縮する修正版である。動画再生、更新、永続データ、対応動画の保証範囲は維持する。

## 主な変更

- デコード済みPCMを音量適用前の有界キューへ保持し、WASAPIが読み出す直前に現在の音量・
  ミュートとリミッターを適用するよう変更した。
- 処理後PCMの保持を最大5 msへ抑え、WASAPI要求レイテンシを20 msとした。
- PCM残量20 ms未満で再バッファへ入り、100 msまで回復してから再開することで、供給間隔が
  変動する場合のアンダーランを防ぐ。
- シーク、速度変更、動画切替ではraw PCM、処理後staging、リミッター先読みを所有単位ごとに
  破棄し、自然終了では全PCMとリミッター末尾を順序どおり出力する。

## v1.1.0からの更新

`v1.1.0`の「ヘルプ」→「更新を確認」から`v1.1.1`へ更新できる。更新時は現在の`data`
フォルダーを保持する。手動更新する場合も、既存の`data`フォルダーを新しい配布フォルダーへ
コピーすると、設定、動画プロファイル、履歴、プレイリストを引き継げる。

## 配布

- Windows 11 x64向けframework-dependent folder ZIP
- .NET 10 Desktop Runtime x64が必要
- バイナリZIPと、LibVLCの対応ソースZIPを同じGitHub Releaseへ掲載
- LibVLC/LibVLCSharpは交換可能な別ファイルとして同梱し、GPL-onlyプラグイン4件は除外

## 既知の制約

- 新しい配布フォルダーでの初回LibVLC初期化はバックグラウンドで約11秒かかる場合があり、その間は
  ウィンドウを操作できるが再生機能は準備完了後に有効になる。
- 自動更新にはGitHubへのHTTPS通信と、展開先フォルダーへの書き込み権限が必要である。失敗時は
  現行版と`data`を変更せず、手動更新へ切り替えられる。
- Windows高コントラスト専用配色は未対応。
- 速度切替直後に短い音飛びが生じる場合がある。
- 4K WMVは性能保証外、HEVC・VP9・VFRはベストエフォート。
- Windowsのファイル関連付けは利用者がOS設定から行い、アプリ内登録・解除機能は持たない。
