# 爆裂おさかな工房 v1.0.1 リリースノート

## 概要

`v1.0.0`のフルスクリーン表示と再生位置スライダーを調整する小規模な修正版である。
設定、動画プロファイル、履歴、プレイリストの保存形式と対応動画の保証範囲は変更しない。

## 修正内容

- フルスクリーン時も、時刻、音量、速度の表示色を通常表示と同じ固定ダークテーマ色に維持する。
- 再生位置スライダーへマウスを重ねた時の標準ツールチップを削除する。
- シーク位置のサムネイルポップアップとアクセシビリティ用の読み上げ名は維持する。

## 配布・更新

- Windows 11 x64向けframework-dependent folder ZIP
- .NET 10 Desktop Runtime x64が必要
- `v1.0.0`はアプリ内更新機能を持たないため、`v1.0.1`はGitHub Releaseから手動でダウンロードする
- 既存の`data`フォルダーを新しい配布フォルダーへコピーすることで設定と利用データを引き継げる

## 既知の制約

- Windows高コントラスト専用配色は未対応
- 速度切替直後に短い音飛びが生じる場合がある
- 4K WMVは性能保証外、HEVC・VP9・VFRはベストエフォート
- Windowsのファイル関連付けは利用者がOS設定から行い、アプリ内登録・解除機能は持たない

## 検証情報

公開候補のcommit、配布ZIP・対応ソースZIPのサイズとSHA-256、品質・配布ゲート結果は
`docs/phase4/v1.0.1-release-candidate-validation.md`へ記録する。
