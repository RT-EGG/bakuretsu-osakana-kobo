要求仕様書

# アプリケーション構成

ウィンドウを持ったアプリケーション。通常は1ウィンドウのみで、将来的に複数ウィンドウを使うことを想定する。
多重起動は不可能。
インストーラー不要。

.exeファイル単体が理想。起動時間に影響がある場合は、.exeと他依存ファイルの構成とする。

# 要求機能

## 動画再生機能

動画ファイルを読み込み、表示する機能。

### 動画を開く導線

以下方法から、動画ファイルを開く機能を作成する。
なお、開かれたファイルは、そのまま再生状態に移行する。

#### ウィンドウのメニューバー

メニューバーに`ファイル`メニューを用意し、その子に`開く`ボタンを作成する。
`ファイル` → `開く`ボタンをクリックした時、ファイル選択ダイアログが表示され、ここで選択されたファイルを再生する。

#### ウィンドウへのドラッグ&ドロップ

ウィンドウを開いている時、そのウィンドウへファイルをドラッグ&ドロップすることで、対象のファイルを再生する。

#### 関連付けした拡張子ファイルの実行

アプリケーションの実行時引数にファイルパスを指定できるようにし、アプリケーションの実行直後、対象のファイルを再生する。

### 対象ファイル

ファーストリリースにおいて、以下を必須とする。

- mp4
- wmv

## 再生動画コントロール

再生中の動画について操作を行う機能。

### シークバー

今、動画のどの位置（時間）を再生中かを表すUI。また、シークバーを操作することで、再生位置を変更することも可能。

### 動画時刻テキスト

今、動画のどの位置（時間）を再生中か、また全体の動画の長さをテキストで表示する。
表示形式は、 `hh:mm:ss / hh:mm:ss` とし、左側に現在位置、右側に全体の動画の長さを描画する。

### 再生/一時停止ボタン

動画の再生を行うボタン。動画の再生中はアイコンが変化し、動画の一時停止ボタンに切り替わる。

### 音量調節

音量調整を行うインジケーター。マウスで操作可能。
0%から500%を調整可能範囲とし、100%を、その動画の最大音量にする。100%移行は、ブーストを行って実現する。

動画再生領域でマウスホイールを操作することでも調整可能。

また、ミュート切り替え機能を実装する。

### フルスクリーン

現在のディスプレイでフルスクリーン表示を行う。

動画再生領域でのダブルクリック、または動画再生領域での右クリックメニューから切り替え可能。

### 再生速度

動画の再生速度を変更する。0.25倍、0.5倍、1.0倍（デフォルト）、1.5倍、2.0倍をサポートする。動画再生領域をマウスクリック長押ししている間、2.0倍で再生する。

動画再生領域での右クリックメニューから切り替え可能。

### サムネイル

シークバーをマウスオーバーすることで、その位置の画像を、シークバー上にポップアップする形でサムネイル表示する。

### キーボードショートカット

キーボードによる、各コントロールの操作を行う。デフォルトの割り当ては以下の通りだが、将来的にカスタマイズができるよう、変数化しておく。（ファーストリリースにおいてはキーバインディングのカスタマイズは不要）

| キー           | 機能                   |
| -------------- | ---------------------- |
| スペース       | 再生/一時停止          |
| カーソルキー ← | 5秒戻る                |
| カーソルキー → | 5秒進む                |
| カーソルキー ↑ | 再生速度を一段階上げる |
| カーソルキー ↓ | 再生速度を一段階下げる |
| Alt+Enter      | フルスクリーン         |

## 動画プロファイル

再生する動画それぞれに対し、再生用のプロファイルを管理する。
プロファイルを管理するファイル群は、.exeと同じ階層のファイル、またはこの階層にプロファイル用のフォルダを作成し、その中で管理する。

プロファイルでは以下の情報を管理する。

### 音量

その動画ファイルを最後に再生していたときの音量。次の再生開始時、音量をこの値に調整する。

### 再生開始位置

その動画ファイルを再生し始めるときの、初期位置（時間）。

動画再生領域での右クリックメニューから、現在の再生位置を再生開始位置として登録可能。

シークバー上に、再生開始位置のマークが表示される。

## プレイリスト

プレイリストを作成、管理する機能。

### 表示

動画再生ウィンドウとは別のウィンドウで表示する。

プレイリスト追加済だが、実際にはその場所にファイルがない場合、ファイルがないことが分かるよう表示を切り替える。

### プレイリストへの追加

以下3導線からプレイリストへの動画ファイルの追加を可能にする。

1. 現在再生中のファイルを追加する
2. プレイリストウィンドウへファイルをドロップする
3. ファイルダイアログから選択する

2,3については、複数のファイルを一括で追加できるようにする。

### プレイリストの並べ替え

リスト上の項目をマウスドラッグすることで並び替えができるようにする。

### プレイリスト上の動画削除

リスト上の項目を選択し、プレイリストから動画を除外できるようにする。

### プレイリストを順番に再生

プレイリストウィンドウに、対象のプレイリストを再生するUIを表示する。
この時、動画が再生されると、プレイリスト上で次の動画を自動で再生する。

## 他

### 最近開いたファイルリスト

`メニューバー` → `ファイル` → `最近開いたファイル` の子アイテムに、直近開いたファイルを最大で10ファイル表示する。

### 関連ディレクトリを開く

設定ファイルなどを作成する場合、そのファイルがあるディレクトリを開くコマンドをメニューバーに作成する。

# 動作環境

デスクトップ。当面はWindows11をターゲットとし、無理のない範囲で他OSをターゲットにする。モバイル対応は不要。

# 他要求

起動、ファイルオープン、ファイル再生といった流れのレスポンスの早さを重要視する。
