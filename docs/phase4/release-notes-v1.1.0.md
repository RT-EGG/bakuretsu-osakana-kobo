# 爆裂おさかな工房 v1.1.0 リリースノート

## 概要

`v1.1.0`は、安全なアプリ内更新と起動時の空シェル先行表示を追加する更新である。
動画再生、動画プロファイル、履歴、単一プレイリストの保存形式と対応動画の保証範囲は維持する。

## 主な変更

- 起動時に1日1回、GitHubの最新の正式Releaseをバックグラウンドで確認する。
- 「ヘルプ」→「更新を確認」から、いつでも手動で新しい版とRelease概要を確認できる。
- 利用者が明示的に同意した場合だけ、固定名のWindows x64 ZIPをダウンロードし、size、SHA-256、
  ZIP構造、`release-manifest.json`、全ファイルを検証する。
- 別プロセスの更新ヘルパーが本体終了後にアプリ所有ファイルだけを置換し、`data`と未知のファイルを
  保持する。失敗時は旧版へロールバックし、安全に自動更新できない場合は手動ダウンロードを案内する。
- ウィンドウを先に操作可能にし、永続データ読込とLibVLC初期化を表示後に行うことで、空シェル表示を
  新規発行先初回を含め1,500 ms以内へ短縮した。

## v1.0.1からの更新

`v1.0.1`はアプリ内更新機能を持たないため、`v1.1.0`だけはGitHub Releaseから手動でダウンロードする。
既存の`data`フォルダーを新しい配布フォルダーへコピーすると、設定、動画プロファイル、履歴、
プレイリストを引き継げる。`v1.1.0`以降はアプリ内更新を利用できる。

## 配布

- Windows 11 x64向けframework-dependent folder ZIP
- .NET 10 Desktop Runtime x64が必要
- バイナリZIPと、LibVLCの対応ソースZIPを同じGitHub Releaseへ掲載
- LibVLC/LibVLCSharpは交換可能な別ファイルとして同梱し、GPL-onlyプラグイン4件は除外

## 既知の制約

- 新しい配布フォルダーでの初回LibVLC初期化はバックグラウンドで約11秒かかる場合があり、その間は
  ウィンドウを操作できるが再生機能は準備完了後に有効になる。
- 自動更新にはGitHubへのHTTPS通信と、展開先フォルダーへの書き込み権限が必要である。失敗時は
  現行版と`data`を変更せず、手動更新へ切り替えられる。
- Windows高コントラスト専用配色は未対応。
- 速度切替直後に短い音飛びが生じる場合がある。
- 4K WMVは性能保証外、HEVC・VP9・VFRはベストエフォート。
- Windowsのファイル関連付けは利用者がOS設定から行い、アプリ内登録・解除機能は持たない。

## 検証情報

公開候補のcommit、配布ZIP・対応ソースZIPのサイズとSHA-256、更新・起動性能・配布ゲート結果は
`docs/phase4/v1.1.0-release-candidate-validation.md`へ記録する。
