## 4. 実音声

既定出力`スピーカー (USBAudio2.0)`のloopbackで、60秒の連続音声を持つ一時検証素材を使用した。安全のためOS音量を一時49%とし、既存のアクティブ音声セッションを一時ミュートした。すべて`finally`で実行前のOS音量100%と各セッション状態へ復元した。一時素材は配布物へ含めない。

| 形式 | 音量・ミュート6操作の可聴反映 | バックエンド反映最大 | 異常診断 |
| --- | ---: | ---: | ---: |
| MP4 | 28.9797～39.4440 ms | 0.3963 ms | 0 |
| WMV | 28.3238～41.9588 ms | 0.3540 ms | 0 |

underrun、overflow、非有限値、範囲外sample、出力失敗は0。100 ms基準に合格した。WMVをMP4直後に即時再オープンした1回はloopbackが全0 sampleとなったため測定失敗として扱い、十分な再オープン間隔を置いた単独再実行で合格した。製品側の音声異常は両回とも0だった。
