# 爆裂おさかな工房 v1.0.0 リリースノート

## 概要

`v0.1.0`で公開した基本再生機能へ、日常利用に必要な音声、表示、Windows連携、履歴、
プレイリスト、サムネイル、異常系処理を追加した正式版である。

## 主な追加機能

- 0～500%音量、ミュート、動画面ホイール操作、動画別の音量・ミュート保存
- 0.25/0.5/1.0/1.5/2.0倍速と、動画面長押し中の一時2.0倍速
- フルスクリーン、3秒後のコントローラー自動非表示、複数画面・異DPI対応
- Space、矢印、Alt+Enter、Escによるキーボード操作
- 動画別の再生開始位置登録とシークバー上のマーカー
- メイン画面への動画ドラッグ&ドロップ
- 起動引数、同一利用者での単一起動、既存ウィンドウへの動画引き渡し
- 最大10件の最近開いたファイル、欠損項目の整理
- 単一プレイリストの保存、追加、削除、並べ替え、連続再生、ループ
- 設定間隔でのシークサムネイル生成、ホバー位置の優先表示
- 偽装・途中破損動画の案内、最後の映像・時刻を維持する再生中エラー
- 粗いドット絵のサカナを用いたアプリケーションアイコン

## 配布・互換性

- Windows 11 x64向けframework-dependent folder ZIP
- .NET 10 Desktop Runtime x64が必要
- 設定・履歴・プレイリストは実行ファイルと同じ場所の`data`配下へ保存
- `v0.1.0`の省略可能な設定項目を後方互換で読み込み、必要な項目を次回保存時に補完
- MP4/WMVの保証範囲は`docs/supported-media-formats.md`を参照

## 既知の制約

- Windows高コントラスト専用配色は未対応
- 速度切替直後に短い音飛びが生じる場合がある
- 4K WMVは性能保証外、HEVC・VP9・VFRはベストエフォート
- Windowsのファイル関連付けは利用者がOS設定から行い、アプリ内登録・解除機能は持たない
